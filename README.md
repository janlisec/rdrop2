# rdrop2 - Dropbox interface from R  ![a_box](docs/rdrop2-logo.png)  

This fork of `rdrop2` is maintained by jan.lisec@bam.de to remain functional 
whenever modifications in the Dropbox API or in imported packages cause the 
implemented `testthat` tests to fail.

As I use `rdrop2` in some of my packages I will try to maintain its functionality 
as good as I can. Feel free to notify me on additional bugs.

For further information on package purpose and functionality see 
https://github.com/karthik/rdrop2.

### Installation of this fork

```
devtools::install_github("janlisec/rdrop2")
```
